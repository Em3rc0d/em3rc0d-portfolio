# Mining Site — Quarries

This area stores external references that influence the portfolio without becoming unquestioned product truth.

Possible quarries:

```text
quarry-0/
quarry-1/
quarry-2/
...
```

Each quarry should record:

```text
SOURCE
WHY IT IS USEFUL
WHAT PATTERN IS BEING STUDIED
WHAT MUST NOT BE COPIED
LICENSE / ETHICAL BOUNDARY IF RELEVANT
TRANSFERABLE IDEAS
PORTFOLIO-SPECIFIC ADAPTATION
```

## Current rule

The generated THE BUILD ROOM concept render belongs in `evidence/visual-references/`, because it is an artifact produced specifically for this portfolio rather than an external donor/reference site.

Future external portfolios, interaction references, motion studies, automotive instrumentation references, or editorial systems can be recorded here when they materially inform implementation.

The goal is provenance and disciplined transfer — not visual cloning.
