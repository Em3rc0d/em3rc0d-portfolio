## Experience and visual specification

Navigation: Systems / Notes / About / Contact. Home: identity → four problem paths and capability families → three editorial system encounters → professional reality → working method → three existing native notes → human context → conversation. Capabilities are disclosures on Home, not a new route. Deep pages: plain-language problem/value/build/state, conceptual model, opt-in architecture/decisions/failure, inspectable evidence, related work. All meaningful information is HTML.

Visual thesis: industrial precision with editorial clarity. Carbon establishes structure; brushed metal belongs to the abstract Build Core; paper holds thought and evidence. Restrained copper and pale blue identify signal/decision states. No fake interfaces, generated product screenshots, counters or terminal metaphors.

Token provenance: existing Instrument Sans / IBM Plex Mono split is OBSERVED and retained. V2 palette, scale, spacing, surfaces and motion are GENERATED design decisions; no brand-official claim. Tokens in `src/styles/tokens.css` are the exact runtime authority. Interface/body ≥16px; regular labels ≥14px; sparse secondary metadata 12–13px. Reading width ≤66ch. Main containers max 1480px. Mobile composition stacks deliberately. A frame grows with content; never require 100vh clipping.

Motion: ENTER / ASSEMBLE / FOCUS / TRANSFER / CONFIRM. Durations 160 / 220 / 400 / 1200ms. Reduced motion: static artifact, no assembly or camera travel. No scroll hijacking. Three.js loads after the readable surface; static geometry composition is always present underneath. Canvas is decorative.
