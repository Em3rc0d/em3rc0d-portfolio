## Learning classification

At the end of the review window:

```text
REPEAT ANGLE
REPEAT FORMAT
REFINE HOOK
REFINE TECHNICAL DEPTH
REFINE AUDIENCE BRIDGE
RETIRE ANGLE
INSUFFICIENT DATA
```

One successful post does not create a permanent rule.

One weak post does not invalidate an editorial territory.

Change the system only when repeated evidence supports the change.
