# Deprecated — Figma Visual Direction v1

**State:** deprecated as final visual direction  
**Preserved because:** it remains useful provenance for the information hierarchy and for understanding why Visual Direction v2 exists.

## What v1 established successfully

The first Figma exploration helped prove:

- Carbon / Paper material contrast;
- semantic navigation;
- primary positioning hierarchy;
- startup parameter concept;
- AutoPulse + CV Engine flagship priority;
- Evidence as a visible portfolio object;
- typography direction;
- technical metadata language;
- dark engineering atmosphere.

## Why it was deprecated

The static composition read too similarly to a modern tech/startup/developer landing page.

Symptoms included:

- oversized sans-serif hero followed by conventional content modules;
- capability cards;
- dark + red + monospace combination that was competent but familiar;
- motion described as annotation rather than determining layout;
- startup acting like a loader before a separate Hero;
- projects still behaving too much like content sections/cards.

The problem was not the underlying portfolio architecture.

The problem was the **composition model**.

## Replacement direction

Replaced by:

`design/STEP-0.8-visual-direction-v2-and-prototype-contract.md`

Core correction:

> **The startup must become the Home. Motion and transformation determine the composition.**

Projects become system moments/inspectable artifacts rather than repeated cards.

## Do not delete old Figma frames

The original Figma frames should remain as historical exploration until the production design is safely established.

They should not be treated as current implementation authority.
